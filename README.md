# QIWI Terminal 2012 — Ностальгическая симуляция

> **Отказ от ответственности (Disclaimer):**  
> Мы никак не связаны с компанией **QIWI**. Это исключительно симуляция интерфейса платёжного терминала 2012 года для ностальгии и ознакомления. Никакие реальные платежи, переводы или сбор данных не производятся.

## Что это
Адаптированный под современные браузеры интерфейс платёжного терминала QIWI образца 2012 года:
- Автоматическая перекодировка `UTF-16LE` / `Windows-1251` → `UTF-8` на лету
- Автомасштабирование терминального разрешения `1280×1024` под экран вашего ПК
- Проверка наличия расширения **Ruffle** при запуске (`index.html` → `terminal.html`)
- Поддержка `POST`-запросов и тестовая панель внесения купюр (`+100`, `+200`, `+500`, `+1000`, `+5000`) на экране оплаты

## Как запустить
1. Убедитесь, что у вас установлен **Python 3**.
2. Для корректного отображения Flash-анимаций установите расширение **[Ruffle](https://ruffle.rs/#downloads)** в ваш браузер.
3. Запустите **`start.bat`** — сервер стартует на порту `8080`, и в браузере откроется страница `http://localhost:8080/index.html`.
4. Нажмите **`F11`** в браузере для полноэкранного режима.
